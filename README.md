# Student Management System — React (V2)

A React-based Student Management System built as an upgraded version of my original C++ project.
V2 was built in early 2026 — this repo exists to deploy and showcase the React version.

## Features
- Add, view, search, update and delete students
- Data persists with localStorage
- Clean responsive UI

## Tech Stack
- React
- JavaScript
- CSS
